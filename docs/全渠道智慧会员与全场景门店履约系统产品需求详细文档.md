# 全渠道智慧会员与全场景门店履约系统 产品需求详细规格说明书 (PRD) - 全场景通用版

---

## 1. 文档概述与核心设计思想

### 1.1 项目背景与定位
面向中小微实体企业（涵盖**餐饮轻食/正餐、美容美发美甲、汽车养护洗车、足浴养生、培训机构、专营零售**等），提供一套低成本部署、极简交互、贴合国内商家与消费者使用习惯的全渠道门店管理系统。
系统涵盖 **PC管理后台 + 员工移动收银App/小程序 + 顾客微信/支付宝小程序**，实现“一次架构开发，全行业通用配置”。

### 1.2 统一核心哲学：“在场履约会话模型 (On-Site Service Session)”
系统打破传统垂直行业软件的壁垒，将餐饮的“扫码开台/点菜/加菜/结账”、美业的“扫码镜台/剪发/加护理/结账”、汽修的“工位入厂/保养/增项/结账”抽象为完全同构的**在场履约会话流**：
1. **物理空间与资源占用**：桌台（餐饮）、镜台/美容床（美业）、工位/举升机（汽修）、包厢（足浴）。
2. **会话开启与身份关联**：顾客主扫或员工反扫，绑定会员或临时访客身份。
3. **初次点单 (Primary Batch)**：底料/套餐（餐饮）、总监剪发（美发）、小保养（汽修）。
4. **过程动态追加 (Append Batch)**：加菜加酒（餐饮）、加精油头皮护理（美发）、加空调滤芯（汽修）、加钟加技师（足浴）。
5. **执行人员与提成按项绑定**：每一项点单可独立挂载 1~N 个施工/服务人员及分成权重。
6. **全渠道混合结算与离场清台**：微信/支付宝/银联/现金/储值卡任意组合抵扣，结账完成后释放空间资源。

## 2. 全渠道多模态支付与财务核算规范

### 2.1 支付通道与硬件协同矩阵

| 支付通道 | 顾客交互形态 | 硬件/接口依赖 | 行业应用场景 |
| :--- | :--- | :--- | :--- |
| **微信支付** | 微信扫桌码/镜台码拉起小程序支付；收银扫码枪被扫出示付款码 | 微信支付直连商户/服务商特约商户 API v3 | 线上充值、扫码先付点餐、离店自决买单、前台聚合扫码。 |
| **支付宝支付** | 支付宝扫码唤起小程序或H5；收银枪反扫付款码 | 支付宝蚂蚁金服当面付/小程序支付接口 | 与微信平行的扫码点单、开卡充值、前台结账。 |
| **银联 / 银行卡** | 刷卡、插卡、挥卡、手机云闪付、数字人民币 | 智能POS机（局域网API/串口驱动直连）或外置收单机记账 | 大额会员充值卡办理、高端养生/汽修大额账单结算。 |
| **现金收银 (Cash)** | 物理货币收找 | RJ11接口智能收银钱箱（驱动脉冲弹开） | 现金支付防错找零计算、大额现钞入柜。 |
| **会员资产抵扣** | 扣储值本金/赠送金、核销次卡、消费积分折抵 | 系统内部核心账户记账引擎 | 锁客复购核心手段，支持跨店划扣。 |
| **多通道混合支付** | 任意 2 种及以上通道拆分结算 | 结算调度引擎原子编排 | 示例：400元账单 = 次卡抵扣1次洗剪吹 + 储值扣150元 + 现金50元。 |

### 2.2 支付、退款与财务对账规则
1. **聚合码智能分流**：单张桌面/工位二维码，微信扫调起微信小程序，支付宝扫调起支付宝小程序。
2. **反扫智能识别**：收银枪扫顾客付款码，系统依据前缀码号自动识别（微信：`10~15`，支付宝：`25~30`），无需收银员手动点选通道。
3. **退款原路冲回与资产合规**：
   - 线上支付部分（微信/支付宝/联机银联）原路退回，支持单笔部分退款。
   - 储值金与次卡部分原路逆向冲回；若包含赠送金，按当时扣除比例同等冲回。
   - 现金退款强制需店长及以上角色输入授权码，杜绝员工私吞现金。
4. **收银班次交接与盲盘平账 (Shift Handover & Reconciliation)**：
   - 收银员交班时执行**现金盲盘**（收银员先数抽屉现金录入系统，系统再展示理论现金，防作弊）。
   - 汇总生成《班次交接单》：包含微信实收、支付宝实收、银联实收、现金实收、储值抵扣、次卡核销、挂单数、长短款差额。

## 3. 在场服务会话与行业通用履约规范

### 3.1 跨行业履约流程与状态机

```
       [空间资源: 空闲 IDLE]
                 │
                 │ 扫码/人工开单 (openSession)
                 ▼
       [会话进行中: SERVING] <────────────────────────┐
                 │                                    │ 过程动态追加项目
                 ├─── 初始点单 (Batch #1)              │ (appendItems)
                 │    - 餐饮: 锅底/热菜                │ - 餐饮: 加菜加酒水
                 │    - 美业: 洗剪吹套餐               │ - 美业: 加头皮护理/烫染
                 │    - 汽修: 换机油小保养             │ - 汽修: 增换刹车油/滤芯
                 │                                    │
                 │ 顾客发起买单 / 前台结算 (requestBilling)
                 ▼
       [待结算锁定: SETTLING] ────────────────────────┘ (允许解挂或返回补录)
                 │
                 │ 组合支付完成 (PaymentSuccess)
                 ▼
       [已结账待复位: SETTLED_WAIT_CLEAN]
                 │
                 │ 翻台/清洁/交车复位 (resetSpace)
                 ▼
       [空间资源: 空闲 IDLE]
```

### 3.2 行业特有能力的“可插拔配置”设计

系统无需更改底层核心代码，通过开店时的“行业模式开关（Business Profile）”动态渲染前台界面与行为：

| 功能维度 | 餐饮模式 (F&B) | 美容美发模式 (Beauty) | 汽修保养模式 (Auto) | 通用底层抽象机制 |
| :--- | :--- | :--- | :--- | :--- |
| **空间资源定义** | 大厅散台、卡座、餐饮包厢 | 剪发镜台、洗头床、美甲工位 | 快修工位、举升机、精洗车位 | **`ServiceSpace` 空间模型** |
| **附加费用策略** | 茶位费、餐具费、包厢服务费 | 洗头一次性毛巾费、造型设计费 | 废机油环保处置费、工时基础费 | **`SessionFeePolicy` 策略** |
| **追加动作副作用** | **网口打印机分单打到厨房档口** | **库房自动预占精油/染膏耗材** | **配件库房自动出库配件** | **`ItemAppendedEvent` 领域事件驱动** |
| **规格与定制备注** | 口味（微辣/免葱）、加料加冰 | 药水品牌、发色色号、卷度要求 | 配件品牌（原厂/品牌）、标号 | **`ItemModifier` 动态属性字典** |
| **提成结算权重** | 传菜员、包厢专属管家分佣 | 发型总监主提成、洗头工辅助提成 | 机修大工 70%、学徒小工 30% | **`PerformerSplit` 提成拆分模型** |

## 4. 全功能模块明细需求

### 4.1 会员与卡券资产管理 (统一六大卡模态)
1. **次卡 (计次消费)**：绑定计量服务项目，支持限制有效期、可用门店及单日核销上限。
2. **储值卡 (双轨核算)**：严格区分本金账户与赠送金账户，消费时按比例协同扣减，退款时优先冲减赠金。
3. **折扣卡 (身份卡)**：根据累计消费或充值自动升降级，支持服务类与实物耗材类独立配置折扣率。
4. **时长卡 (周期卡)**：周卡、月卡、季卡、年卡，在时间窗口内每日配额或无限次享受特定项目。
5. **套餐盒卡 (复合卡)**：实物耗材 + 计量服务项 + 代金券的自由组装包，支持子项目单独消次与分工提成。
6. **付费权益卡 (PLUS会员)**：按月/年付费订阅，解锁专属低价与每月定期定投卡券。
7. **无卡消费检索**：手机尾号 4 位检索、人脸识别核验、动态 60 秒刷新防伪二维码。

### 4.2 商品与耗材进销存管理
1. **商品品类解耦**：
   - **实物零售品**：带物理库存，支持扫条码出入库。
   - **计量服务项**：纯工时虚拟项，不占物理库存，计入员工施工提成。
   - **原料耗材 (BOM配方)**：服务关联消耗（如做一次烫发消耗 1 瓶药水，餐饮一份牛排扣减 200g 牛肉原料）。
2. **多仓调拨与盘点**：总仓与分店仓调拨申请、出库审核、到店点验；不停业动态盘点，自动生成盘盈盘亏凭单。

### 4.3 员工组织与提成核算
1. **四级权限控制 (RBAC)**：超级管理员（老板）、店长、收银员、技师/服务员。
2. **多维提成引擎**：
   - 售卡提成（充值本金按比例或固定金额分成）。
   - 施工工时提成（按项目一口价或结算毛利提成）。
   - 多人协同分成（主工/副工自定义百分比）。
3. **员工自助端**：技师/员工在移动端实时查看个人接单工单、客户评价、当日提成。

### 4.4 微信/支付宝私域营销
1. **一键扫码开卡**：顾客扫桌码/工位码，调用平台授权手机号，3 秒免密入会并赠送新人礼券。
2. **全渠道动账推送**：充值、消次、加菜消费秒级推送微信服务通知或支付宝生活号消息。
3. **营销裂变套件**：老带新分销返佣、限时秒杀、拼团、线上工位/技师预约。
